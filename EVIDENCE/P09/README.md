# P09: Software Bill of Materials (SBOM) & SCA

## Назначение
Эта директория содержит:
1. **SBOM** - инвентаризация компонентов программного обеспечения
2. **SCA** - отчеты анализа безопасности зависимостей

## Процесс генерации

### SBOM Generation
Автоматически генерируется при:
- Push в main/master
- Создании тегов (релизов)
- Ручном запуске workflow

### SCA Analysis
Запускается после генерации SBOM:
1. Сканирование SBOM на уязвимости с помощью Grype
2. Создание детального отчета в JSON
3. Генерация человекочитаемой сводки в Markdown
4. Комментирование PR с ключевыми находками

## Форматы файлов

### SBOM
- **Формат:** SPDX JSON
- **Имя:** `sbom-{commit-SHA}.json`
- **Инструмент:** Anchore Syft v0.102.1

### SCA Reports
1. **sca_report.json** - полный отчет Grype в JSON
   - Все найденные уязвимости
   - Детальная информация о каждом CVE
   - Ссылки на базы знаний

2. **sca_summary.md** - агрегированная сводка
   - Статистика по severity (Critical, High, Medium, Low)
   - Ключевые находки с описанием
   - План действий для исправления
   - Сравнение с предыдущими сканированиями

## Настройка исключений

Ложные срабатывания настраиваются в:
- `.github/grype-config.yaml` - централизованная конфигурация
- `.grype.yaml` - локальная переопределения (опционально)
