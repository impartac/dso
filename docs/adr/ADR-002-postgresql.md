# ADR 001: Выбор PostgreSQL с SQLAlchemy ORM
## **Status : Accepted**

## **Context:**
Требуется обеспечить
* **NFR-4** (защита от инъекций)
* **NFR-6** (приватность данных).
* **NFR-1** требует надежного хранения аудит-логов.

## **Рассматривались альтернативы:**
* **MongoDB** - риск NoSQL-инъекций (NFR-4), слабая консистентность для аудита
* **MySQL** - менее гибкая JSON поддержка для метаданных медиа(NFR-3)

## **Solution:**
Использовать PostgreSQL + SQLAlchemy Core (не ORM) для данных, SQLAlchemy ORM для аудита.

## **Обоснование:**

* Параметризованные запросы по умолчанию - полная защита от SQL-инъекций (NFR-4)

* Row-Level Security - может обеспечить изоляцию данных на уровне БД

* JSONB поддержка - гибкое хранение метаданных медиа с валидацией

* Транзакционная надежность - критично для аудит-логов (NFR-1, NFR-2)

* pgcrypto extension - для шифрования чувствительных полей (NFR-6)

## **Consequences:**

✅ Гарантированная защита от SQL-инъекций

✅ Надежное ACID-хранение аудит-событий

✅ Возможность маскирования данных на уровне БД

⚠️ Сложнее горизонтальное масштабирование

⚠️ Требует миграций схемы
