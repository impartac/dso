# Security NFR для Media Catalog

## NFR-1: Защита аутентификации
- **Субъект**: Система аутентификации
- **Условие**: При неуспешных попытках входа
- **Порог**: >=5 неудачных попыток за 5 минут с одного IP
- **Поведение**: Блокировка IP на 15 минут, возврат унифицированного сообщения
- **Доказательство**: Событие `auth_ip_blocked` в аудит-логе с correlation_id

## NFR-2: Лимит создания медиа
- **Субъект**: Endpoint POST /media
- **Условие**: Для аутентифицированного пользователя
- **Порог**: Не более 10 запросов в минуту на создание медиа
- **Поведение**: HTTP 429 + Retry-After: 60 сек при превышении
- **Доказательство**: Событие `rate_limit_triggered` с rule_id="media_create"

## NFR-3: Маскирование ошибок
- **Субъект**: Все endpoints API
- **Условие**: При любых ошибках 4xx/5xx
- **Порог**: 100% ошибок без технических деталей
- **Поведение**: Унифицированное сообщение "Произошла ошибка", маскирование email, ПДН в логах
- **Доказательство**: Отсутствие stack trace, email, ПДН в телах ответов и логах

## NFR-4: Защита от инъекций
- **Субъект**: Все SQL/NoSQL запросы
- **Условие**: При обработке пользовательского ввода
- **Порог**: 0 успешных инъекций в penetration testing
- **Поведение**: Валидация и параметризация всех запросов, отклонение подозрительных паттернов
- **Доказательство**: Отчет динамического тестирования безопасности (DAST)

## NFR-5: Валидация JWT токенов
- **Субъект**: Система аутентификации
- **Условие**: При каждом API запросе
- **Порог**: 100% проверок подписи и expiration
- **Поведение**: Отклонение токенов с истекшим сроком, невалидной подписью
- **Доказательство**: Логи jwt_validation_failed с причиной отказа

## NFR-6: Приватность данных
- **Субъект**: ПДН данные (email)
- **Условие**: Хранение и передача данных
- **Порог**: Маскирование в логах
- **Поведение**: Маскирование email в формате u***@d***.com, маскирование ПДН в формате {PII}
- **Доказательство**: Отсутствие ПДН и email в *.log

## NFR-7: Управление сессиями
- **Субъект**: Система аутентификации
- **Условие**: Для активных сессий
- **Порог**: Таймаут 60 минут неактивности
- **Поведение**: Secure cookie flags (HttpOnly, Secure), инвалидация сессий при logout, rotation session tokens
- **Доказательство**: Тесты безопасности, проверка cookie attributes


## NFR-8: Защита от DoS атак
- **Субъект**: Public endpoints
- **Условие**: При высокой нагрузке (>100 rps)
- **Порог**: Выдерживание 3x нормальной нагрузки
- **Поведение**: Rate limiting, WAF, автоматическое масштабирование, graceful degradation
- **Доказательство**: Load testing отчет, метрики доступности при атаке
